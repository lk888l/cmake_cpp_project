# Cross-compilation toolchain guide

[中文](TOOLCHAIN_GUIDE_cn.md) | **English**

## Overview

The project supports three build modes:

1. **arm-linux**: Buildroot `aarch64-buildroot-linux-gnu`
2. **aarch64-gnu**: standard `aarch64-none-linux-gnu`
3. **local-x86**: local development build

## Building with aarch64-none-linux-gnu

### Prerequisites

Install the AArch64 GNU toolchain:

```bash
# Ubuntu/Debian
sudo apt-get install gcc-aarch64-linux-gnu g++-aarch64-linux-gnu

# Or download a standalone package from:
# https://developer.arm.com/Tools-and-Software/GNU-Toolchain
```

### Option A: discover the toolchain from PATH

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=aarch64-gnu \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

### Option B: provide a custom toolchain path

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=aarch64-gnu \
    -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64-none-linux-gnu.cmake \
    -DTOOLCHAIN_PATH=/path/to/toolchain/bin \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

### Option C: provide a sysroot

Use a target root filesystem when target headers or libraries are required:

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=aarch64-gnu \
    -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64-none-linux-gnu.cmake \
    -DSYSROOT_PATH=/path/to/sysroot \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

## Compiler comparison

### aarch64-buildroot-linux-gnu (`arm-linux`)

- Comes from the Buildroot build system.
- Includes the sysroot generated by Buildroot.
- Best suited to an existing Buildroot environment.

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=arm-linux \
    -DBUILDROOT_DIR=/path/to/buildroot/output
cmake --build build -j$(nproc)
```

### aarch64-none-linux-gnu (`aarch64-gnu`)

- Standard, officially maintained GNU Arm toolchain.
- Independent of Buildroot.
- Accepts an independently selected sysroot.
- Follows conventional CMake cross-compilation practice.

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=aarch64-gnu \
    [-DSYSROOT_PATH=/path/to/sysroot]
cmake --build build -j$(nproc)
```

## Toolchain-file design

The `aarch64-none-linux-gnu.cmake` file follows these rules.

### Modern CMake

```cmake
set(CMAKE_SYSTEM_NAME Linux)
set(CMAKE_SYSTEM_PROCESSOR aarch64)
set(CMAKE_TRY_COMPILE_TARGET_TYPE STATIC_LIBRARY)
```

### Flexible compiler discovery

```cmake
# Discover from PATH
find_program(CMAKE_C_COMPILER NAMES aarch64-none-linux-gnu-gcc REQUIRED)

# Or select an explicit location
set(CMAKE_C_COMPILER "${TOOLCHAIN_PATH}/aarch64-none-linux-gnu-gcc")
```

### Standard search-path policy

```cmake
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)   # Host programs
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)    # Target libraries
set(CMAKE_FIND_ROOT_PATH_MODE_INCLUDE ONLY)    # Target headers
```

### Compile and link flags

```cmake
set(CMAKE_C_FLAGS_INIT "-march=armv8-a")
set(CMAKE_EXE_LINKER_FLAGS_INIT "--sysroot=${CMAKE_SYSROOT}")
```

### pkg-config

```cmake
set(ENV{PKG_CONFIG_SYSROOT_DIR} ${CMAKE_SYSROOT})
set(ENV{PKG_CONFIG_LIBDIR} "${CMAKE_SYSROOT}/usr/lib/pkgconfig:...")
```

## Frequently asked questions

### How do I verify the selected compiler?

```bash
cmake -S . -B build -DTARGET_PLATFORM=aarch64-gnu -DCMAKE_BUILD_TYPE=Release

# CMake output should contain:
# C Compiler:          /usr/bin/aarch64-none-linux-gnu-gcc
# C++ Compiler:        /usr/bin/aarch64-none-linux-gnu-g++
```

### How is it used in CI?

```yaml
- name: Compile with aarch64-gnu
  run: |
    cmake -S . -B build \
      -DTARGET_PLATFORM=aarch64-gnu \
      -DCMAKE_BUILD_TYPE=Release
    cmake --build build -j4
```

### Static or dynamic linking?

Both toolchains default to static linking. To disable it, change
`USE_STATIC_LINKING` in `CMakeLists.txt`:

```cmake
set(USE_STATIC_LINKING OFF CACHE BOOL "Use static linking")
```

### What if the toolchain cannot be found?

Make sure one of the following is true:

1. the tools are in `PATH`;
2. `-DTOOLCHAIN_PATH` points to the toolchain `bin` directory;
3. the toolchain is installed and the following commands work:

```bash
aarch64-none-linux-gnu-gcc --version
aarch64-none-linux-gnu-g++ --version
```

## Build examples

### Quick Release build

```bash
cd /path/to/example_thread
cmake -S . -B build -DTARGET_PLATFORM=aarch64-gnu
cmake --build build -j$(nproc)
ls -lh build/src/example_thread
```

### Debug build

```bash
cmake -S . -B build \
    -DTARGET_PLATFORM=aarch64-gnu \
    -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

### Deploy to the target

```bash
scp build/src/example_thread root@172.18.25.50:/home/
```
